# MoonVPN

Власний VPN на Raspberry Pi з блокуванням реклами, трекерів і шкідливих сайтів, плюс Android-додаток **Lumen** з однією великою кнопкою.

- **Сервер:** WireGuard + AdGuard Home в Docker. Встановлюється одним файлом і сам піднімається після вимкнення світла.
- **Додаток:** 3D-планета із супутником (рендер шейдером на GPU). Коли VPN увімкнено, між ними з'являється зв'язок, по якому біжать частинки даних.

## Структура

```
server/     сервер для Raspberry Pi (docker compose + install.sh)
android/    Android-додаток Lumen (Kotlin, Jetpack Compose, AGSL)
docs/       скріншоти
```

## Запуск сервера (Raspberry Pi / будь-який Linux)

Потрібно: Linux з systemd, білий IP (або домен) і доступ до налаштувань роутера. Docker не обов'язковий: якщо його немає, скрипт поставить сам, а якщо є, не чіпає.

1. Скопіюй папку `server/` на малинку:
   ```bash
   scp -r server pi@<IP-малинки>:~/moonvpn
   ```
2. Зайди на малинку і запусти інсталятор:
   ```bash
   ssh pi@<IP-малинки>
   cd ~/moonvpn && sudo ./install.sh
   ```
   Якщо зовнішній IP не визначився сам: `sudo ./install.sh --host мій.домен.або.IP`.
3. На роутері прокинь **UDP 51820** на IP малинки.
4. Інсталятор надрукує QR-код і збереже конфіг у `server/clients/phone.conf`.

Що робить `install.sh`:
- піднімає контейнери `wireguard`, `adguard`, `filterctl`, `autoheal`;
- генерує пароль панелі AdGuard (`server/adguard-password.txt`);
- вмикає автозапуск: systemd-сервіс, перевірку кожні 5 хвилин, апаратний watchdog. Після вимкнення світла все стартує саме;
- налаштовує ufw (відкриті лише 22/tcp і 51820/udp), fail2ban і автооновлення безпеки.

Корисні команди:
```bash
sudo ./install.sh add tablet     # додати ще один пристрій
sudo ./install.sh show phone     # показати QR повторно
docker compose ps                # стан контейнерів
```

Панель AdGuard доступна тільки зсередини VPN (`http://10.8.1.2:3000`) або через SSH-тунель:
```bash
ssh -L 3000:localhost:3000 pi@<IP-малинки>
```
Порт панелі на хості змінюється змінною `UI_PORT` у `server/.env`.

## Android-додаток

### Встановлення
Збери APK (нижче) і встанови його:
```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

### Перше підключення
1. Відкрий додаток → шестерня внизу → **Сканувати QR** (QR з `install.sh`), **Імпорт з файлу** або **Вставити з буфера**.
2. Натисни на планету й дозволь VPN-з'єднання.

### Налаштування
- **Сервер:** змінити адресу або порт без повторного імпорту.
- **Списки блокування:** вмикай і вимикай HaGeZi (Light / Multi / Pro / Pro++ / Ultimate / Threat Intelligence), OISD Big / Small, AdGuard DNS, URLhaus, StevenBlack, 1Hosts та інші. Працює, коли VPN увімкнено. Зміна застосовується на сервері за 1–2 хвилини.
- **Сайти:** «усе через VPN, крім списку» або «лише список через VPN».
- **Застосунки:** те саме для встановлених застосунків.
- **Запуск після перезавантаження**.
- **Блокувати все без VPN:** відкриває системний «Постійний VPN» (kill switch).

### Збірка
Потрібно: JDK 17, Android SDK (platform 34, build-tools 34).
```bash
cd android
echo "sdk.dir=/шлях/до/Android/Sdk" > local.properties
./gradlew assembleDebug
```
На Windows: `gradlew.bat assembleDebug`, а в `local.properties` шлях пишеться через `/`, наприклад `C:/Users/<you>/AppData/Local/Android/Sdk`.

3D-сцена потребує Android 13+. На старіших версіях показується спрощена 2D-кнопка.

## Приватність і захист

- WireGuard (ChaCha20-Poly1305) з додатковим preshared key для кожного клієнта; весь IPv4 та IPv6 трафік іде через тунель.
- DNS: AdGuard Home → DNS-over-HTTPS (Quad9, Cloudflare) з DNSSEC. **Журнал запитів і статистика вимкнені.**
- Назовні відкритий лише UDP 51820. API фільтрів (`10.8.1.4:8080`) доступний тільки зсередини VPN.
- Межі: VPN ховає трафік від провайдера й публічного Wi-Fi. Сайти бачать IP твоєї домашньої мережі, а DNS-провайдер бачить домени (без прив'язки до тебе).

## Обмеження

- Списки блокування глобальні для сервера: AdGuard Home не вміє різні списки для різних пристроїв.
- Фільтр сайтів працює за IP-адресами, які визначаються в момент підключення. Сайти за CDN можуть міняти адреси.
